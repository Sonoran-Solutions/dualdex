2. Contrast with Experimental Build (pokehns-release.elf)
================================================================================
An experimental LTO build (`pokehns-release.elf`) compiled with `-flto=auto`
reordered global symbols in EWRAM:

  nm pokehns-release.elf:
    0200026c B gLastUsedAbility
    020002f4 B gFieldStatuses
    02000300 B gBattleControllerExecFlags

In that experimental build, gFieldStatuses was at 0x2F4 and gBattleControllerExecFlags
was at 0x300. Previous DualDex investigations mistakenly consulted this ELF instead
of the official release ROM binary, causing:
1. §11.5 / §11.6 to cite 0x02000300 for gBattleControllerExecFlags.
2. §14 to configure DualDex reader with `.field_statuses_offset = 0x2F4`.
On the actual official release ROM (SHA-256 edf76ecf...), 0x2F4 is
gBattleControllerExecFlags and 0x2E8 is gFieldStatuses.

3. Official Release ROM Disassembly: gBattleControllerExecFlags at 0x020002F4
================================================================================
Target function: IsBattleControllerActive(u8 battler)
Source: src/battle_controller.c:
  bool32 IsBattleControllerActive(u8 battler) {
      return (gBattleControllerExecFlags & (1 << battler)) != 0;
  }

ARM Thumb disassembly in Pokémon Heart and Soul (v2.0.5).gba at 0x08056C00:

  08056c00: 2301      movs  r3, #1
  08056c02: 0600      lsls  r0, r0, #24
  08056c04: 0e00      lsrs  r0, r0, #24
  08056c06: 4083      lsls  r3, r0          ; r3 = (1 << battler)
  08056c08: 4a0a      ldr   r2, [pc, #40]   ; loads [0x08056C34]
  08056c0a: 6812      ldr   r2, [r2, #0]    ; r2 = *0x020002F4
  08056c0c: b500      push  {lr}
  08056c0e: 421a      tst   r2, r3          ; test (*0x020002F4 & (1 << battler))
  08056c10: d00b      beq.n 0x08056C2A

Literal pool at 0x08056C34:
  08056c34: 020002f4  .word 0x020002f4      ; Address of gBattleControllerExecFlags

This conclusively proves that on the official release ROM, 0x020002F4 is
gBattleControllerExecFlags (NOT gFieldStatuses). When battler 0 executes its
controller loop, bit 0 is set (0x00000001).
